Philosophy

Open source, not a SaaS.

Oni is a tool you own. The daemon runs on your machine, the worktrees live on your disk, and the interface is a local web app or your terminal. There is nothing to subscribe to.

01

Free, with source

MIT-licensed code. Read it, fork it, run it offline, or change how the loop works. No open-core bait and switch.

02

No accounts, no seats

No login, no usage meter, no hosted control plane. Your repo and your model credentials stay where you put them.

03

Built for one human

Agents do the work. You review the real patch and decide. Oni is a cockpit, not an autonomous deployment pipeline.

The system

Small surface. Sharp edges.

Every task is a contract: prompt, acceptance check, isolated branch, and a human at the gate. The daemon owns git isolation; the agent only owns its worktree.

01

Worktree per task

Agents never write to the base branch. Each task gets a fresh worktree and an oni/<slug> branch.

02

Verification loop

Your command decides. Oni reinjects the failure, retries within a bounded budget, and restores the verifier from the base branch.

03

Human merge

Review the unified patch, then merge with --no-ff. Stop, retry, accept verification changes, or discard without cleaning up a mess.

Install

From zero to a TUI.

Rust 1.88+, Node 22+, git, and an agent CLI. The PWA is embedded in the daemon binary. 

# clone the repo
git clone https://github.com/Davoassassin27/oni
cd oni

# build the embedded PWA and the daemon
npm install
npm run build
cargo build --release --manifest-path oni-daemon/Cargo.toml

# terminal 1: run the daemon
./oni-daemon/target/release/oni-daemon

# terminal 2: install and open the TUI
cargo install --path oni-daemon --bin oni --locked
oni

Principles

Boring where it matters.

  • 01 No agent writes to the base branch.
  • 02 Verification is mandatory before review.
  • 03 The verifier is restored from the base branch.
  • 04 Merge is always a human action.
  • 05 No accounts, no cloud, no telemetry.
  • 06 Mobile first, one hand, 44 px targets.
